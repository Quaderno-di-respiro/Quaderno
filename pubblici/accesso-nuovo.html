Nuovo accesso

Prepara il link personale per aprire il Quaderno e il messaggio da mandare. Il codice nasce su questo telefono: la pagina non lo manda a nessuno. Lo tiene solo finché chiudi questa scheda.

Ti propongo il primo libero tra quelli creati da questo telefono. Se hai creato accessi da un altro telefono, controlla su GitHub quali numeri ci sono già.

Accessi creati da questo telefono

Qui ci sono solo numero, nome e data, mai i codici. Restano su questo telefono.

    Passo 1 di 3

    Crea il segreto su GitHub

    Name

    Secret

    Apri GitHub › Nuovo segreto

    Se GitHub dice che quel nome c'è già, il numero è occupato: . Il codice resta lo stesso.

    Passo 2 di 3

    Ripubblica il sito

    1. Apri Actions › Pubblica.
    2. Tocca Run workflow, poi di nuovo Run workflow.
    3. Aspetta la spunta verde: un paio di minuti.
    Apri Actions › Pubblica

    Passo 3 di 3

    Manda il messaggio

    Mandalo solo a questa persona, quando il link funziona. Niente dati sulla salute nei messaggi.

    Puoi cambiarlo anche adesso: il codice resta lo stesso, cambia solo il link nel messaggio.

    Per togliere un accesso

    Su GitHub, in Settings › Secrets and variables › Actions, cancella il segreto della persona (il cestino accanto a ACCESSO_ e il suo numero). Poi ripubblica il sito (Actions › Pubblica › Run workflow): il suo link e il suo codice smettono di funzionare. Il numero torna libero.
